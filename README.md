# Python for Absolute Beginners — 6-Week Course

A beginner-friendly, no-experience-required introduction to Python, built for people coming from **non-technical backgrounds**. One hour a day, hands-on from day one, entirely in your browser via **Google Colab** — no installs, no setup headaches.

## Who this is for

- You've never written a line of code before, or you tried once and it didn't stick.
- You want to learn by doing, not by watching theory-heavy lectures.
- You can commit to a **1-hour class, 5 days a week, for 6 weeks**.

No prior programming knowledge is assumed. The only requirement is a Google account (for Colab) and curiosity.

## How the course works

- Each day is a **single Colab notebook** with explanations, runnable examples, and exercises mixed together.
- Every week ends with a **review/buffer day** — extra practice time, catch-up on anything tricky, and a small mini-project that pulls the week's topics together.
- By the end, you'll build a **portfolio-ready final project** using real data.

## Course outline

| Week | Topic | Focus |
|------|-------|-------|
| 1 | Python Fundamentals | Colab basics, variables, data types, operators, conditionals, loops |
| 2 | Collections & Functions | Lists, tuples, dictionaries, sets, writing functions |
| 3 | Strings, Robust Code & Files | String formatting, error handling, reading/writing files, modules |
| 4 | Object-Oriented Programming | Classes, objects, constructors, inheritance |
| 5 | Working with Data | List comprehensions, NumPy, Pandas, Matplotlib/Seaborn |
| 6 | APIs, Web Data & Final Project | Requests, JSON, web scraping basics, final project |

A full day-by-day breakdown is in [`6-week_Python_course_outline.docx`](./6-week_Python_course_outline.docx).

## Getting started

1. Click on any day's notebook in this repo.
2. Click the **"Open in Colab"** badge at the top of the notebook (or open [Google Colab](https://colab.research.google.com) and upload the file manually).
3. Make a copy to your own Google Drive so you can save your work: **File → Save a copy in Drive**.
4. Follow along and run each cell — try the exercises before checking the solution cells.

No installation, no environment setup — everything runs in the cloud.

## Prerequisites

- A free [Google account](https://accounts.google.com) (for Colab and Drive).
- A web browser.
- That's it.

## Final project — Quiz Game with 20 Questions

The course wraps up with a comprehensive final project that ties together everything from Weeks 1–6: a **command-line quiz game with 20 questions**, built entirely in a single Colab notebook.

It brings together:

- **Week 1** — variables, user input, and loops to run the quiz flow
- **Week 2** — lists and dictionaries to store questions/answers, functions to organize the game logic
- **Week 3** — string manipulation for formatting questions/feedback, error handling for invalid input, file I/O for saving results
- **Week 4** — OOP (classes) to model the quiz and player
- **Week 5** — Pandas, NumPy, and Matplotlib to score, summarize, and visualize quiz performance
- **Week 6** — optional bonus API integration

You can find it in [`final-project/quiz_game.ipynb`](./final-project/quiz_game.ipynb). It's a good example of what you'll be able to build by the end of the course — and a great one to show off on GitHub or LinkedIn.
